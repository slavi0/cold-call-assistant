# Cold Call Assistant

A modern cross-platform application built with **Flutter**.

## Overview
Cold Call Assistant helps track, manage, and analyze cold calling workflows and interactions.

## Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.10.8 or newer)
- Android Studio / Xcode / VS Code with Flutter extension

### Running the App
```bash
# Get dependencies
flutter pub get

# Run the app
flutter run
```

### Running Tests & Analysis
```bash
# Run static analysis
flutter analyze

# Run unit tests
flutter test
```
